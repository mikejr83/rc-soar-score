RC Soar Score contest app - Windows alpha {{VERSION}}
=====================================================

This is an alpha for contest directors to try next to GliderScore. It runs
offline on this computer. There is no account and no sign-in in this build.

Install
  1. Unzip this folder anywhere you like (not inside Program Files).
  2. Run soar_score_contest.exe.
  3. Windows may show "Windows protected your PC" because the app is not
     signed yet. Click "More info", then "Run anyway".

Where your contests are
  Contests are stored in your user profile (the application support folder),
  not in this folder. Deleting or replacing this folder does not touch them.
  Back up your contests by copying that folder.

Update
  Download the newer zip, close the app, unzip it and replace this folder.
  Your contests are kept.
