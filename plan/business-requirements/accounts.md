# RC Soar Score Business Requirements

The RC Soar Score solution is a set of applications and APIs to track, score, and publish results for radio controlled sailplane contests. The users of the software may create accounts in order to use various functions of the software.

## Non-Account Functionality

A contest director using the offline capabilities of the application will not need any account. The data is stored locally. The contest director is the owner and can modify the data such as the scoring.

Participants can be invited to enter scores online. These users are not required to create an account. The application should generate a special URL that is sent to the participant.

A contest director may publish a public contest without creating an account.

Users viewing the public contests do not need an account.

## Account Related Functionality

Contest directors can create accounts. This will enable the syncing of any offline data to service layer.

Participants can create accounts. This enables contest directors to search and find them from an online database to add to contests.
