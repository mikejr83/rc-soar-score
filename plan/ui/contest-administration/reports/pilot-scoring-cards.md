# Reports & Documents - Pilot Scoring Cards

Pilot scoring cards are generated for pilots to have a physical "card" to track their scores. The cards contain all the information when a pilot flies. It gives them a spot to enter each of the components that make up their score for their discipline. Additionally, the score card contains a QR code invite link to their online scoring interface.

## Heading

There are two parts to the heading, a small header that appears at the top of the card and one that appears for the pilot's identity.

### Card Header

The title containing the contest name, venue, and date should appear as text across the top of each card. This text can be smaller, it doesn't have to be title text.

### Pilot Identity

The main header or title for the card should be the pilot's identity. This consists of their name along with the following information (shown smaller).

* Club
* FAI and National ID
* Class\*
* Team\*

\* Only shows if the contest is configured for them.

## QR Code

If online scoring has been enabled a QR code should be displayed on the card. It needs to be big enough that an inkjet printer set to "document quality" can print it without issue (it shouldn't be so small that high resolution is needed).

## Scoring Table

The main part of the card is the display of a table for the pilot to keep track of when they fly and spots to record their score components.

The table starts with the following columns:

* Round Number
* Group
* Lane Number\*

\* Only if this is enabled for the contest.

Additional columns are displayed based on the score components for the contest's discipline.

F5J Example:

* Time
* Landing
* Height
* Over 75m
* Motor Restart\*

\* If enabled by the contest.

Finally three additional columns:

* Penalty
* Timer
* Validated

## Printing

These cards should be designed such that they can fit into quadrants of a standard letter or A4 sheet of paper. Two cards can be displayed per page when contests have a large number of rounds. A guideline border should be drawn for the cards so that they may easily be cut to size.

## Options

**Pre-fill** - If scores have been entered then this becomes a enabled. It is not set by default. When it is set the score components will be prefilled into the cards where they're available.

## Filtering

The user should be able to select a range of rounds to print. The default is to show/print all rounds. The user should also be able to select which pilots they want to show/print. By default all pilots are shown.
