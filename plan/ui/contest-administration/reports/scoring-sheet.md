# Reports & Documents - Scoring Sheet

This sheet is a simple tabular layout for officials to be able to write in score components for a hard-copy of scores. This is typically used at regional, national, or world level contests.

## Heading

The heading for each page should say "Official Scoring - {Contest_Name}". A subheading under this should include the venue and the contest dates.

## Basic Layout

This is document is a tabular layout that enables officials to write down each score component for each pilot.

The columns start with:

- Pilot Name
- Club
- Lane Number\*
- Team\*
- Pilot Number\*
- Pilot Class\*

\* If the contest has this enabled.

The next columns consist of the components that are recorded for scoring the contest discipline.

F5J Example:

- Time
- Landing
- Height
- Over 75m
- Motor Restart\*

\* If the contest has this enabled.

These columns then follow:

- Penalty
- Reflight
- Original Round
- Validated

The table should be ordered by round and then by the groups within the round. A header should appear at the point where the round starts. A header should appear at the point where a group starts.

The pilots should be ordered in ascending lane assignment number if lane assignments have been enabled for the contest.

## Options

The following columns can be hidden/shown:

- Club
- Team
- Pilot Number
- Pilot Class
- Validated

## Filtering

The report needs to be able to be filterable so that a select set of rounds can be selected. It should default to "All rounds". An lower and upper bound for rounds (inclusive) should be able to be set so such that the output show from the lower to the upper rounds.
