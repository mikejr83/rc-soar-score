# RC Soar Score Participant Scoring

The document in this folder defines the mobile-first participant score-entry and score-review experience.

## Documents

- [`participant-scoring.md`](participant-scoring.md) - Invitation-based participant score entry and review.

## Design briefs

Prompts handed to a design tool to produce visual designs, kept in [`briefs/`](briefs/). They summarize the requirement documents and are not themselves requirements; when a brief and a requirement document disagree, the requirement document wins.

- [`briefs/self-scoring.md`](briefs/self-scoring.md) - Design prompt for the self-scoring app (landing, invitation, contests, team overview, pilot overview, score entry, results).
