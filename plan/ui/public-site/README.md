# RC Soar Score Public Site UI

The documents in this folder define the UI which make up the public site for contest search and viewing results.

## Documents

- [`contest-not-found.md`](contest-not-found.md) - The page shown when a contest cannot be displayed.
- [`contest-search.md`](contest-search.md) - Public contest search and result filtering.
- [`docs-help.md`](docs-help.md) - Documentation and help pages.
- [`homepage.md`](homepage.md) - Public site landing page.
- [`support.md`](support.md) - Support request form.
- [`view-contest.md`](view-contest.md) - Published contest and results viewing.
