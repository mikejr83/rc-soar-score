# RC Soar Score Public Site UI - Support

A page for submitting a support request is presented to users.

The page will have a form requesting the following information:

* Name - Required
* Email - Required
* User type - Not required and should default to blank. Has the following options in a section:
  * Contest Director
  * Pilot
  * Participant
* Request Type - Required
  * Public site issue - Contests not displaying, site errors, etc.
  * Contest Management - Questions about running contests, admin, etc
  * Online Score Entry - Trouble entering scores or questions about online scoring.
  * Feature Request - New features are always coming. Help shape the application!
  * User Account Inquiry - Trouble registering, accessing the site, etc.
  * General Inquiry - Questions or comments that don't fall into another category.
  * Emergency Contest Issue - A critical issue around running a contest or entering scores.
* Message - A freeform text entry box. Limited to 2000 characters.

This form will use a captcha service to prevent and limit spam input.

After submitting the form the user will be shown a thank you message.
