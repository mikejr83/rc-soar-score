gliderscore import helper - vendored third-party binaries

Binaries in this directory (bin/x86/), with SHA-256 checksums. Verify them
after downloading, e.g. with `sha256sum` (or `Get-FileHash -Algorithm SHA256`
on Windows). The checksums equal the SHA-256 of each prebuilt artifact as
committed in the fork repo at the commit below, so the shipped files can be
checked against the exact upstream build:

Source:
  The mdb JSON helpers are the MinGW32 (MSYS2) build of mdbtools from
  https://github.com/mdbtools/mdbtools (GPLv2 / LGPL), vendored from the
  fork https://github.com/lsgunth/mdbtools-win, pinned to commit
  cefdd6d277b77a36f2073106c71ec84c65bece2d (master). The MinGW runtime
  DLLs (libgcc, libiconv, libwinpthread) come from the same toolchain.
  The corresponding source is the mdbtools source at that commit, together
  with the MinGW-W64 source for the runtime DLLs. It is publicly available
  at that commit, and we make a written offer to provide a copy of the
  corresponding source to anyone in possession of these binaries, free of
  charge, upon request.

These executables and libraries are shipped as separate files and run as a
separate process; they are never linked into Soar Score.

They are 32-bit Windows binaries and run under WoW64 on x64 Windows. No C or
C++ toolchain is required for the Soar Score build; CMake installs these
files, together with the license texts, next to the app (see README.md and
docs/windows-installer-requirements.md).
